# 포켓몬 신규 등록 및 메가진화 추가 종합 가이드 (POKEMON ADD GUIDE)

본 문서는 일반 포켓몬, 폼체인지, 메가진화 포켓몬 및 관련 시스템(종족값, 특성, 기술, 도구, 실전 샘플, 스프라이트)을 코드베이스에 신규 등록할 때 따르는 **단일 절대 기준(Single Source of Truth)**입니다.
외부 AI 어시스턴트나 개발자는 본 문서의 규칙만을 읽고 즉시 정확하게 작업을 수행할 수 있도록 작성되었습니다.

---

## 0. 공식 데이터 준수 및 추측 작성 금지/고지 의무 (Canonical Truth)

### 0-1. 명확한 공식 정답이 존재하는 항목 (PokemonData / Skill / Item)
- **대상**:
  - 포켓몬의 **전국도감 번호, 종족값(HP/공격/방어/특공/특방/스피드), 타입, 특성**
  - 기술의 **위력, 명중률, PP, 우선도, 기술 설명, 부가효과**
  - 도구의 **공식 명칭, 인게임 설명 텍스트**
- **규칙**:
  - 위 항목들은 공식 게임 원작에 정확한 정답이 존재하므로 **임의로 추측하거나 상상해서 작성해서는 안 되며**, 반드시 공식 인터넷 출처에서 정확한 값을 조회하여 작성해야 합니다.
  - 본가에 존재하지 않는 오리지널 메가진화이거나, 미공개 정보로 인해 부득이하게 종족값, 특성, 기술, 도구 설명 등을 **추측하거나 창작하여 작성한 경우**, **작업 완료 후 반드시 사용자에게 어떤 항목을 어떤 근거로 추측/창작했는지 명시적으로 고지(언급)**해야 합니다.

### 0-2. 실전 샘플 데이터 (SamplePokemon) 작성 원칙
- **대상**:
  - `pokemonSampleList.js`에 등록되는 실전 샘플 스펙 (**노력치 `evs`, 성격 보정 `up`/`down`, 기술배치 4개 `sk1~sk4`, 지닌도구 `item`, 시작특성 `abil`, 역할군 `role`, `tip`**)
- **규칙**:
  - 샘플은 `PokemonData`와 달리 단 하나의 공식 정답이 존재하는 것은 아니지만, **본 프로젝트에서는 무조건 사용자가 어떤 값으로 구성할지 알려줍니다.**
  - 따라서 **AI가 임의로 인터넷 메타나 본인 판단으로 샘플을 추측하여 작성하지 마십시오.**
  - **사용자가 프롬프트에서 실전 샘플 구성 정보를 제공하지 않았다면, 임의로 샘플을 만들지 말고 반드시 사용자에게 "실전 샘플(노력치, 성격, 기술배치 4개, 지닌도구, 특성, 역할군) 정보를 알려주세요"라고 추가 정보를 요청**해야 합니다.

## 1. 공식 데이터 인터넷 출처

포켓몬 및 기술, 도구의 정확한 공식 스펙은 다음 신뢰할 수 있는 출처를 통해 조회합니다:

1. **한국어 출처 (우선 권장)**:
   - **포켓몬위키 (Pokémon Wiki)**: `https://ko.pokemon.fandom.com/wiki/{포켓몬이름}`
     - 전국도감번호, 타입, 종족값(HP, 공격, 방어, 특수공격, 특수방어, 스피드), 특성 목록, 공식 기술 및 도구 설명
   - **나무위키**: `https://namu.wiki/w/{포켓몬이름}`
     - 세대별 포켓몬 정보, 메가진화/폼체인지 상세 종족값, 특성 설명, 아이템 설명
2. **글로벌 / 영문 데이터베이스**:
   - **Serebii.net**: `https://www.serebii.net/` (전국도감, 종족값, 특성, 기술 세부 플래그)
   - **Bulbapedia**: `https://bulbapedia.bulbagarden.net/` (공식 설명, 메커니즘, 기술 플래그)
   - **PokemonDB**: `https://pokemondb.net/pokedex/{포켓몬영문명}`

## 2. 규격 및 식별자(ID) 규칙

1. **전국도감 번호 (`dexNo`)**:
   - 4자리 0 채움(Zero-padded) 문자열
   - 예: `"0006"` (리자몽), `"0970"` (킬라플로르), `"0998"` (드닐레이브)
2. **식별키 (`uniqueKey` / `id`)**:
   - 일반 포켓몬: 전국도감 번호 4자리와 동일 (예: `"0970"`)
   - 메가진화 포켓몬: `{4자리도감번호}-m` (예: `"0970-m"`)
   - 복수 메가진화 및 폼체인지:
     - 메가리자몽X: `"0006-x"`, 메가리자몽Y: `"0006-y"`
     - 메가한카리아스Z: `"0445-z"`
     - 알로라 나인테일: `"0038-a"`, 가라르 불비달마: `"0555-g"`
3. **종족값 (Base Stats)**:
   - 공식 출처에서 각 수치(HP, 공격, 방어, 특수공격, 특수방어, 스피드)를 정확히 조회하여 입력합니다.
   - **주의**: 메가진화라고 해서 임의로 특정 공식(예: 무조건 +100)을 전제하여 계산하지 말고, 공식 출처에 기재된 실제 종족값 수치를 그대로 입력합니다.
4. **타입**:
   - `type1`: 1타입 (예: `"바위"`, `"불꽃"`)
   - `type2`: 2타입. 단일 타입인 경우 `null`, 복합 타입인 경우 2타입 문자열 (예: `"독"`, `"비행"`)
5. **특성 (`abilList`)**:
   - 일반 포켓몬: 획득 가능한 일반/숨겨진 특성 배열 (예: `["독치장", "부식"]`)
   - 메가진화 포켓몬: 진화 후 고정 특성 1개를 담은 배열 (예: `["적응력"]`)

## 3. 기술 풀 (PokemonSkillList) 등록 원칙 (중요)

- **파일 경로**: `src/entity/Skill/PokemonSkillList.js`
- **구조**:
  - `core`: 주력 기술 목록 (자속 핵심 공격기, 주요 유틸/랭크업/상태이상기)
  - `others`: 그 외 포켓몬이 배울 수 있는 기술 목록
- **기술 목록 작성 원칙**:
  - **사용자가 프롬프트에서 기술 목록을 직접 제공한 경우**: 사용자가 전달한 목록에 맞춰 `core`와 `others`를 채워 넣습니다.
  - **사용자가 기술 목록을 제공하지 않은 경우**:
    - AI가 임의로 인터넷에서 기술 목록을 긁어오거나 상상해서 채우지 **않습니다**.
    - 반드시 `core: []`, `others: []`로 **빈 배열 상태**로 등록합니다.
    - 작업을 마친 후 사용자에게 **"해당 포켓몬의 주력 기술(core)과 배울 수 있는 기술(others) 목록을 제공해주세요"라고 명시적으로 요청**합니다.

## 4. 도구 및 메가스톤 등록 원칙 (중요)

- **파일 경로**: `src/entity/Item.js`, `src/component/customScreen/sampleInfo/ItemSearchModal.js`
- **도구 등록 절차**:
  1. `src/entity/Item.js`의 `itemText` 객체에 도구 설명 등록
  2. 메가스톤 등 탈취/교체 불가 도구인 경우 `src/entity/Item.js`의 `noNullItem` 배열에 등록 (탁쳐서떨구기, 트릭 방지)
  3. 전용 도구인 경우 `src/component/customScreen/sampleInfo/ItemSearchModal.js`의 `EXCLUSIVE_ITEMS` 객체에 포켓몬 매칭 함수 등록
- **도구 설명 조회 출처**:
  - 포켓몬위키, 나무위키, Serebii 등에서 인게임 공식 도구 툴팁 텍스트를 조회하여 정확히 기재합니다.
- **[절대 금지: 도구 이미지 파일 조작 금지]**:
  - **`public/img/item/` 디렉터리의 이미지 파일은 절대로 추가, 복사, 수정, 삭제하지 마십시오.**
  - 이미지가 없더라도 다른 도구 이미지를 임의로 복사해서 채우지 않습니다.
  - **도구 이미지는 사용자가 직접 넣으므로 AI는 코드 상의 등록 작업만 수행합니다.**

## 5. 실전 샘플 등록 원칙 및 스펙 (`pokemonSampleList.js`)

- **파일 경로**: `src/entity/Pokemon/pokemonSampleList.js`
- **클래스 정의**: `src/entity/Pokemon/pokemonSample.js`

### 5-1. 생성자 시그니처
```javascript
new samplePokemon(sampleName, uniqueKey, evs, up, down, sk1, sk2, sk3, sk4, item, abil, role, tip = "", img_id = null);
```

| 파라미터 | 타입 | 설명 및 예시 |
| :--- | :--- | :--- |
| **`sampleName`** | `string` | 샘플 고유 이름 (예: `"킬라플로르"`, `"메가킬라플로르"`, `"썬더 (특수)"`) |
| **`uniqueKey`** | `string` | **원본 기본 도감번호 4자리** (예: `"0970"`). **메가진화 샘플이라도 `"0970-m"`이 아닌 기본 도감번호 `"0970"`을 입력**합니다. (배틀 시작 시 기본 폼으로 출전 후 메가진화 트리거를 거치기 때문) |
| **`evs`** | `string` | 노력치 표준 약어 문자열 (예: `"CS252"`, `"AS252"`, `"HB252"`, `"HA252"`, `"HD252"`, `"HC252"`, `"BD252"` 등) |
| **`up`** | `string` | 성격 상승 스탯 (`"atk"`, `"def"`, `"catk"`, `"cdef"`, `"speed"` 중 하나. HP 불가) |
| **`down`** | `string` | 성격 하락 스탯 (`"atk"`, `"def"`, `"catk"`, `"cdef"`, `"speed"` 중 하나. HP 불가) |
| **`sk1 ~ sk4`** | `string` | 실전 기술배치 4개 (예: `"파워젬"`, `"오물웨이브"`, `"대지의힘"`, `"니들가드"`) |
| **`item`** | `string` | 지닌도구 (메가진화 포켓몬의 경우 전용 메가스톤 `"킬라플로르나이트"`) |
| **`abil`** | `string` | **시작 특성** (메가진화 포켓몬의 경우 **메가진화 전 기본 특성**을 지정. 배틀 중 메가진화 시 `MegaData.js`의 메가 특성으로 자동 교체됨) |
| **`role`** | `string` | 유효 역할군 8개 중 하나 (`"물리어태커"`, `"특수어태커"`, `"물리막이"`, `"특수막이"`, `"기점잡이"`, `"물리딜탱"`, `"특수딜탱"`, `"막이"`) |
| **`tip`** | `string` | (선택) 운용 팁 문자열. **팁은 사용자가 직접 작성하는 경우가 많으므로 기본값 빈 문자열(`""`)로 두거나 사용자가 제공한 경우에만 작성** |
| **`img_id`** | `string` | (선택) 특별한 커스텀 이미지가 필요한 경우가 아니면 기본값 `null` |

### 5-2. 세부 파라미터 규칙
1. **노력치 (`evs`) 약어 표기법**:
   - `CS252`: 특공 252, 스피드 252, 잔여 4
   - `AS252`: 공격 252, 스피드 252, 잔여 4
   - `HB252`: 체력 252, 방어 252, 잔여 4
   - `HA252`: 체력 252, 공격 252, 잔여 4
   - `HD252`: 체력 252, 특방 252, 잔여 4
   - `HC252`: 체력 252, 특공 252, 잔여 4
   - `BD252`: 방어 252, 특방 252, 잔여 4
2. **역할군 (`role`) 필수 8종류**:
   - `"물리어태커"`, `"특수어태커"`
   - `"물리막이"`, `"특수막이"`, `"막이"`
   - `"물리딜탱"`, `"특수딜탱"`
   - `"기점잡이"`
3. **정렬 및 배치 순서**:
   - `pokemonSampleList.js`의 `this.items` 배열은 **전국도감 번호 오름차순**으로 정렬되어 있습니다.
   - 동일 도감번호에 일반과 메가진화 샘플이 모두 존재하면 **일반 샘플을 먼저, 메가진화 샘플을 바로 뒤에 배치**합니다.

## 6. 단계별 코드 등록 절차 및 상세 예시

### Step 1. 포켓몬 기본 데이터 등록 (`src/entity/Pokemon/PokemonData.js`)

`PokemonDataList` 클래스의 `this.items` 배열에 **전국도감 번호 순서**에 맞춰 등록합니다.

- **생성자 시그니처**:
  ```javascript
  new Pokemon(dexNo, uniqueKey, name, hp, atk, def, catk, cdef, speed, type1, type2, abilList, feature);
  ```
  *(참고: `feature`는 선택 인자로, 미진화체 `{ evo: true }`, 초전설/환상 `{ legendary: true }` 등을 전달)*

```javascript
// [일반 포켓몬 예시]
new Pokemon("0970", "0970", "킬라플로르", 83, 55, 90, 130, 81, 86, "바위", "독", ["독치장", "부식"]),

// [메가진화 포켓몬 예시 (ID 접미사 -m)]
new Pokemon("0970", "0970-m", "메가킬라플로르", 83, 90, 105, 150, 96, 101, "바위", "독", ["적응력"]),
```

---

### Step 2. 메가진화 관계 데이터 매핑 (`src/entity/Pokemon/MegaData.js`)

메가진화가 가능한 포켓몬인 경우, `megaDataList` 객체에 기본 포켓몬의 도감번호를 키로 매핑합니다:

```javascript
"0970": [
  {
    stone: "킬라플로르나이트",
    megaFormId: "0970-m",
    name: "메가킬라플로르",
    abil: "적응력",
  },
],
```

---

### Step 3. 기술 별칭 및 기술 풀 등록 (`src/entity/Skill/PokemonSkillList.js`)

1. **메가진화 폼 별칭 (`POKEMON_SKILL_ALIASES`)**:
   ```javascript
   메가킬라플로르: "0970-m",
   ```
2. **기술 풀 (`POKEMON_SKILLS`)**:
   - 사용자가 기술 목록을 제공했을 때:
     ```javascript
     "킬라플로르": {
       core: ["오물웨이브", "파워젬", "스텔스록", "대지의힘"],
       others: ["에너지볼", "맹독", "러스터캐논", "맹독압정", "빛의장막"]
     },
     ```
   - 사용자가 기술 목록을 제공하지 않았을 때 (빈 배열로 등록 후 요청):
     ```javascript
     "킬라플로르": {
       core: [],
       others: []
     },
     ```

---

### Step 4. 특성 등록 및 엔진 연동 (`src/entity/Ability.js`)

엔진에 등록되지 않은 신규 특성인 경우 `abilObject`에 공식 설명을 추가합니다:

```javascript
부식: { text: "강철타입이나 독타입 포켓몬도 독 또는 맹독 상태로 만들 수 있다." },
적응력: { text: "자신과 같은 타입인 기술의 위력이 올라간다." },
```
*(배틀 판정 로직이 필요한 경우 `src/function/ailment.js`, `src/util/damageCalculate.js`, `src/service/onHit.js` 등에 구현)*

### Step 5. 도구 등록 (`src/entity/Item.js` & `ItemSearchModal.js`)

1. **`src/entity/Item.js`**:
   ```javascript
   // 도구 설명 등록 (인터넷 공식 텍스트 조회)
   킬라플로르나이트: "킬라플로르에게 지니게 하면 배틀 중 메가진화할 수 있다.",

   // 도구 탈취 방지 등록
   export const noNullItem = [
     // ...
     "킬라플로르나이트",
   ];
   ```
