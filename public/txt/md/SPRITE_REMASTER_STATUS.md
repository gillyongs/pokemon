# 포켓몬 스프라이트 고화질 리마스터 작업 현황 및 가이드

이 문서는 포켓몬 2D 배틀 스프라이트(128×128 규격 포켓몬 및 메가진화 포켓몬)의 고화질 AI 리마스터 및 규격화 작업의 진행 현황과 다음 작업을 위한 상세 가이드입니다.

---

## 1. 핵심 원칙 및 품질 기준 (반드시 준수)

1. **철저한 2D 애니메이션 / 공식 도트·일러스트 스타일 유지**:
   - ⚠️ **3D 모델(Pokémon HOME 모델, 입체 CGI 렌더) 사용 절대 금지**.
   - 반드시 깔끔한 외곽선과 셀 채색(Cel-shading)을 가진 **공식 2D 배틀 스프라이트 그림체**여야 합니다.
2. **원본 디자인 및 배틀 자세(포즈/실루엣) 엄격 준수**:
   - AI가 자체적으로 포즈를 역동적이랍시고 과장하거나 해부학적 비율을 왜곡해서는 안 됩니다.
   - 원본 레퍼런스(`public/img/pokemon/backup/{id}.webp`)의 **바라보는 방향, 머리 각도, 팔다리 배치, 실루엣**을 그대로 유지해야 합니다.
   - *(실패 사례: 메가대짱이와 메가입치트의 경우 AI가 임의로 포즈를 재해석하여 원본에서 너무 벗어나 반려 및 롤백됨)*
3. **누끼(투명화) 기준**:
   - 외곽 배경은 물론, **몸통-날개-꼬리-팔다리 사이에 갇힌 내부 배경 구멍(Holes)**도 완전히 투명화해야 합니다.
   - 단, 캐릭터의 신체 부위인 **이빨, 눈 흰자위, 발톱/손톱 등 흰색 파츠**는 누끼로 파이지 않고 온전히 보존되어야 합니다.
4. **캔버스 규격 및 정렬**:
   - 파일 포맷: `256×256`, 무손실 WebP (`.webp`)
   - 정렬: 좌우 중앙 정렬, 하단 여백 `bottomPad: 2px` (바닥에 닿는 기본 포켓몬 기준)
   - 부유형 포켓몬(예: 레지에레키 `0894`)은 공중에 뜬 느낌을 위해 하단 여백(`bottomPad: 24px`)을 부여합니다.

## 3. 리소스 및 파이프라인 가이드

### (1) 이미지 생성 API 쿼터 현황
- **모델**: Gemini Image (Image Generation Subagent)
- **현 상태**: `429 RESOURCE_EXHAUSTED` (2026-10-21 18:26 소진)
- **복구 예상**: 약 4시간 40분 뒤 (2026-10-21 23:10 전후)

### (2) 누끼 및 후가공 파이프라인 스크립트
위치: `scripts/process_ai_sprite.js`
- **주요 기능**:
  - 외곽 4면 플러드 필로 1차 배경 분리.
  - 600px 이상의 내부 갇힌 흰색 구멍(`[Background Hole]`)을 감지하여 자동 투명화.
  - 600px 미만의 이빨/눈/발톱 등 캐릭터 신체 부위(`[Character Detail]`)는 자동으로 보존.
  - 256×256 캔버스 하단 패딩(`bottomPad: 2`) 및 좌우 중앙 정렬 후 무손실 WebP 저장.
- **실행 예시 (Node.js)**:
  ```js
  const { processAiSprite } = require('./scripts/process_ai_sprite.js');
  const path = require('path');

  processAiSprite(
    'C:/Users/khs20/.gemini/antigravity/brain/{conversationId}/{generated_image}.jpg',
    path.join(__dirname, 'public/img/pokemon/0260-m.webp'),
    {
      targetMaxW: 230,
      targetMaxH: 200,
      bottomPad: 2,
      previewPngPath: path.join(__dirname, 'public/img/pokemon/test_0260-m_ai.png')
    }
  );
  ```

### (3) 프롬프트 작성 시 주의사항
다음 세션에서 AI에 이미지를 요청할 때 **반드시 아래 문구를 프롬프트에 포함**해야 합니다:
```text
STRICT REQUIREMENT: Do NOT invent or alter the battle stance, proportion, or angle.
Replicate the exact silhouette, camera perspective, limb orientation, and battle pose from the reference image at [reference_path].
Style: Official Pokémon 2D anime battle sprite with sharp cel-shaded black outlines.
ABSOLUTELY NO 3D models, NO 3D CGI, and NO dynamic reimagining. It must be an exact 1:1 high-resolution 2D remaster of the reference sprite.
Solid pure white background.
```
